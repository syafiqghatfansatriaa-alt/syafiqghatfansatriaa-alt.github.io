THE DIGITAL LEADERSHIP SPACE — WEBSITE 2.0

Isi paket:
- index.html
- style.css
- app.js
- assets/ (foto dokumentasi yang dikirim)

CARA MEMASANG DI GITHUB (ANDROID)
1. Unduh dan ekstrak ZIP ini di aplikasi File/Files.
2. Buka repositori GitHub: syafiqghatfansatriaa-alt.github.io.
3. Pastikan salinan Website 1.0 sudah aman. Paket ini tidak mengubah 1.0 dengan sendirinya.
4. Untuk uji coba, unggah isi paket ke branch/repository terpisah terlebih dahulu bila tersedia.
5. Setelah dites, unggah index.html, style.css, app.js, dan folder assets ke root branch main.
6. Jika GitHub menanyakan penggantian index.html, lakukan hanya setelah yakin backup 1.0 tersedia.
7. Tunggu GitHub Pages selesai deploy, lalu cek situs di Chrome.

CATATAN
- Contact form memakai mailto: pesan disiapkan di aplikasi email pengunjung; tidak ada server penyimpan pesan.
- Foto kelompok ditampilkan sebagai dokumentasi; pastikan izin publikasi dari orang-orang yang terlihat, terutama bila masih di bawah umur.
- Tidak ada audio autoplay. Opening portal dapat dilewati.
- Peran/riwayat ditulis hati-hati sesuai informasi yang sudah tersedia; periksa kembali sebelum publikasi.
- File foto disimpan lokal dalam folder assets, bukan di-host pihak ketiga.
